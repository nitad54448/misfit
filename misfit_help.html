Le Bail Two-Phase Refinement

A short guide to the controls, the math, and the diagnostics.

What it does

Misfit performs an iterative Le Bail extraction on a powder diffraction pattern with two phases refined simultaneously. Lattice parameters can optionally be constrained to be equal between the two phases — useful for misfit layered compounds and composites where one or more cell edges are shared. Peak widths follow the GSAS Profile 4 (Caglioti) parameterisation; the peak shape itself is a pseudo-Voigt, by default in the Thompson–Cox–Hastings form. The background is estimated by a rolling-ball morphological filter and held fixed during the main refinement.

Workflow

  • Load a 2θ–intensity pattern with the file picker (top of the controls panel). Many lab formats are auto-detected: .xy, .csv, .txt, .xrdml, .brml, .ras, .gsa, .udf, .esd, .std.
  • Pick the Bravais system and centering for each phase, then enter starting cell parameters. Tick the boxes next to a parameter to mark it for refinement.
  • Use the Constraints section to tie equivalent parameters between phases (e.g. shared a and c for an in-plane–coherent intergrowth).
  • Adjust the rolling-ball radius and pre-smoothing on the Background tab until the orange line tracks the baseline cleanly between peaks.
  • Open the Profile tab to choose the profile function, set the GSAS Profile 4 coefficients, and set instrumental corrections. Refinement flags are independent per parameter.
  • Click Run Refinement. Choose Levenberg–Marquardt for fast local convergence with ESDs, or Simulated Annealing (the default) if the starting point is poor. Both methods minimise the same weighted objective, so switching between them does not change what is being fitted.

Lattice parameters

Inputs are in ångströms (cell edges) and degrees (cell angles). Only parameters that exist for the chosen Bravais system are shown — choosing Cubic (F), for example, hides everything except a. The reflection-allowed conditions for P, I, F, C, and R lattices are applied automatically when generating the (hkl) list. For monoclinic and rhombohedral cells the l index is scanned over negative values as well, since (hkl) and (hk-l) are not equivalent when the cross term is present.

Peak widths — GSAS Profile 4 coefficients

The peak width is split into a Gaussian and a Lorentzian contribution, each with the standard Caglioti-type angular dependence:

σ² = GU·tan²θ + GV·tanθ + GW + GP/cos²θ    [centidegrees²] HWHMₗ = LX/cosθ + LY·tanθ    [centidegrees]

These are converted internally to FWHM in degrees via ΓG = σ·√(8·ln2)/100 and ΓL = 2·HWHMₗ/100.

GU
Microstrain-like Gaussian broadening (∝ tan²θ).
GV
Cross term in the Caglioti expression. Often slightly negative.
GW
Constant Gaussian instrument width (the irreducible floor).
GP
Gaussian crystallite-size term (∝ 1/cos²θ). Rarely refined for X-rays.
LX
Lorentzian crystallite-size broadening (∝ 1/cosθ).
LY
Lorentzian microstrain broadening (∝ tanθ).
Warning Nothing prevents GU/GV/GW/GP from driving σ² negative (or LX/LY driving the Lorentzian HWHM negative) at some angles. The width is floored at a near-delta value when that happens, and the refinement will emit a warning to the console and to the PDF report. A fit that triggers this warning is in an unphysical corner of parameter space and should not be trusted — fix or re-start the offending coefficient rather than accepting the result.

Peak shape — profile function

The Profile fn. selector on the Profile tab chooses how ΓG and ΓL are combined into a single peak shape.

TCH pseudo-Voigt (default)

The Thompson–Cox–Hastings approximation to the true Voigt function. A single effective width Γ and a mixing fraction η are derived from the two component widths:

Γ = (ΓG⁵ + 2.69269·ΓG⁴ΓL + 2.42843·ΓG³ΓL² + 4.47163·ΓG²ΓL³ + 0.07842·ΓGΓL⁴ + ΓL⁵)1/5 q = ΓL/Γ    η = 1.36603·q − 0.47719·q² + 0.11116·q³

Both the Gaussian and the Lorentzian component then share the same Γ. In this mode the η input is disabled and its refinement flag is cleared: η is not a free parameter, it is a function of the Caglioti coefficients. This is the physically correct behaviour and is what you want in almost all cases.

Empirical pV (free η)

A purely empirical mixture, in which the Gaussian keeps width ΓG, the Lorentzian keeps width ΓL, and η is an independent refinable knob:

pV(x) = η·L(x; ΓL) + (1−η)·G(x; ΓG)
η
Mixing fraction, empirical mode only. η = 0 → pure Gaussian, η = 1 → pure Lorentzian.

This form is self-consistent and area-normalised, but η is decoupled from the real Voigt convolution, so the Caglioti coefficients no longer carry their usual physical meaning. Use it only when you deliberately want an extra shape degree of freedom, and do not interpret LX/LY as size/strain in that case. The profile function actually used is recorded in both the text and PDF reports.

Normalisation and truncation

Both forms are area-normalised, so the integrated intensities returned by the Le Bail extraction do not depend on peak width or shape. Because a pseudo-Voigt is normalised over an infinite range but can only be evaluated over a finite one, each peak is evaluated out to ±15·FWHM and the small remaining truncation is then corrected analytically (an error function for the Gaussian part, an arctangent for the Lorentzian part). Without that correction a Lorentzian-dominated peak loses several percent of its area, and the loss depends on the width — which would bias the intensity partitioning exactly where area normalisation is meant to prevent it.

The Le Bail extraction

At every refinement step the observed (background-subtracted) intensity is partitioned among all contributing reflections in proportion to their current calculated contributions, and the partition is iterated to self-consistency:

Ik(new) = Σi yobs(i) · [ Ik·Ωk(i) ] / Σk' Ik'·Ωk'(i)

Ωk is the normalised profile of reflection k. The intensity weighting is what makes this Le Bail rather than a plain profile deconvolution: partitioning by Ω alone would split every overlapping pair by width only — 50/50 for equal widths — and could never recover the true intensity ratio. Twenty cycles are run per refinement step, and intensities are carried forward between steps as a warm start. Reflections are initialised equal on the first pass, per Le Bail's original prescription, and negative values are clamped to zero.

Note Extracted intensities are channel sums, so their absolute magnitude scales roughly as 1/Δ2θ and will change if you re-bin your data. Ratios between reflections, and the fit itself, are unaffected — an overall linear scale factor is determined analytically and absorbs it.

Sample displacement & transparency

Two systematic 2θ shifts are available. Both coefficients are stored in centidegree units, so the contributions are (in degrees):

Δ(2θ)shft = −2·shft·cosθ / 100 Δ(2θ)trns = trns·sin(2θ) / 100
shft
Vertical sample displacement (Bragg–Brentano geometry only).
trns
Sample transparency / X-ray penetration depth (flat-plate reflection only).
zero
Constant 2θ zero offset, applied to all peaks of both phases.
Caveat Do not refine zero, shft, and lattice parameters together — they are strongly correlated and the refinement will pick up false minima. A pragmatic order is: refine cell parameters first with zero fixed at 0, then release shft or trns as appropriate for your geometry, then re-refine the cell.

Diagnostics

Rp
Profile residual: 100 · Σ|yobs−ycalc| / Σ|yobs|.
Rwp
Weighted profile residual, with Poisson weights wi = 1/max(yi, 1).
χ²ᵣ
Reduced chi-squared, Σw·(yobs−ycalc)² / (N−P). The goodness-of-fit GoF = √χ²ᵣ is shown alongside in the report.

Both Levenberg–Marquardt and Simulated Annealing minimise the same weighted sum of squares, using the same Poisson weights, with the overall linear scale factor profiled out analytically (s = Σw·yobs·ycalc / Σw·ycalc²) so that the arbitrary absolute level of the extracted intensities does not enter the residual.

The difference curve (red, below the pattern) is the most informative diagnostic. Sinusoidal residuals around peaks indicate an unfit cell parameter or zero offset; symmetric residuals that are too sharp or too broad at the peak top indicate a width problem (LX, LY, or the Caglioti terms); residuals that change character systematically with 2θ point at the wrong angular dependence rather than the wrong magnitude.

On the ESDs Standard deviations in the PDF report come from the Levenberg–Marquardt covariance matrix and should be read as lower bounds. They are built from the profile-parameter Jacobian only: the Le Bail intensities and the profiled-out scale factor are extra degrees of freedom that absorb part of the residual but are not propagated. Le Bail refinements are inherently optimistic this way — treat the numbers as a guide to relative precision, not as absolute uncertainties. A singular matrix (reported as such) means two or more refined parameters are completely correlated; fix one of them.

Plot interaction

  • Mouse wheel inside the plot: zoom on both axes.
  • Mouse wheel over the x-axis: zoom 2θ only. Same for the y-axis.
  • Click and drag: pan.
  • Right-click anywhere on the plot: reset zoom.
  • The 2θ-min / 2θ-max sliders below the controls trim the fitting range; everything outside is shown but excluded from the refinement.

Output

Save Report writes a plain-text report containing the refined parameters, the profile function used, the reflection list with calculated and nearest observed d-spacings and 2θ values, and a full data table of experimental intensity, calculated pattern, and difference on the full 2θ grid. Generate PDF produces a multi-page report with the plot, the refinement statistics, refined parameters with their estimated standard deviations (LM only), and the reflection list sorted by 2θ.
