Le Bail Two-Phase Refinement

A short guide to the controls, the math, and the diagnostics.

What it does

Misfit performs a Le Bail extraction on a powder diffraction pattern with two phases refined simultaneously. Lattice parameters can optionally be constrained to be equal between the two phases — useful for misfit layered compounds and composites where one or more cell edges are shared. The peak shape is GSAS Profile 4 (pseudo-Voigt with the standard Cagliotti / Lorentzian-broadening parameterisation). The background is estimated by a rolling-ball morphological filter and held fixed during the main refinement.

Workflow

  • Load a 2θ–intensity pattern with the file picker (top of the controls panel). Many lab formats are auto-detected: .xy, .csv, .txt, .xrdml, .brml, .ras, .gsa, .uxd.
  • Pick the Bravais system and centering for each phase, then enter starting cell parameters. Tick the boxes next to a parameter to mark it for refinement.
  • Use the Constraints section to tie equivalent parameters between phases (e.g. shared a and c for an in-plane–coherent intergrowth).
  • Adjust the rolling-ball radius and pre-smoothing on the Background tab until the orange line tracks the baseline cleanly between peaks.
  • Open the Profile tab to set GSAS Profile 4 coefficients and instrumental corrections. Refinement flags are independent per parameter.
  • Click Run Refinement. Choose Levenberg–Marquardt for fast local convergence with ESDs, or Simulated Annealing if the starting point is poor.

Lattice parameters

Inputs are in ångströms (cell edges) and degrees (cell angles). Only parameters that exist for the chosen Bravais system are shown — choosing Cubic (F), for example, hides everything except a. The reflection-allowed conditions for P, I, F, C, and R lattices are applied automatically when generating the (hkl) list.

GSAS Profile 4 coefficients

The peak full-width-at-half-maximum is split into a Gaussian and a Lorentzian contribution, with the standard Caglioti and Thompson–Cox–Hastings forms:

σ² = GU·tan²θ + GV·tanθ + GW + GP/cos²θ    [centidegrees²] HWHMₗ = LX/cosθ + LY·tanθ    [centidegrees]
GU
Microstrain-like Gaussian broadening (∝ tan²θ).
GV
Cross term in the Caglioti expression. Often slightly negative.
GW
Constant Gaussian instrument width (the irreducible floor).
GP
Gaussian crystallite-size term (∝ 1/cos²θ). Rarely refined for X-rays.
LX
Lorentzian crystallite-size broadening (∝ 1/cosθ).
LY
Lorentzian microstrain broadening (∝ tanθ).
η
Pseudo-Voigt mixing fraction. η = 0 → pure Gaussian, η = 1 → pure Lorentzian.

Both component profiles are area-normalised, so integrated intensities returned by the Le Bail extraction do not depend on the peak width.

Sample displacement & transparency

Two systematic 2θ shifts are available. Both coefficients are stored in centidegree units, so the contributions are (in degrees):

Δ(2θ)shft = −2·shft·cosθ / 100 Δ(2θ)trns = trns·sin(2θ) / 100
shft
Vertical sample displacement (Bragg–Brentano geometry only).
trns
Sample transparency / X-ray penetration depth (flat-plate reflection only).
zero
Constant 2θ zero offset, applied to all peaks of both phases.
Caveat Do not refine zero, shft, and lattice parameters together — they are strongly correlated and the refinement will pick up false minima. A pragmatic order is: refine cell parameters first with zero fixed at 0, then release shft or trns as appropriate for your geometry, then re-refine the cell.

Diagnostics

Rp
Profile residual: 100 · Σ|yobs−ycalc| / Σ|yobs|.
Rwp
Weighted profile residual, with Poisson weights wi = 1/max(yi, 1). The quantity actually minimised by LM.
χ²ᵣ
Reduced chi-squared, Σw·(yobs−ycalc)² / (N−P). The goodness-of-fit GoF = √χ²ᵣ is shown alongside in the report.

The difference curve (red, below the pattern) is the most informative diagnostic. Sinusoidal residuals around peaks indicate an unfit cell parameter or zero offset; asymmetric residuals indicate a profile-shape problem (try refining LX, LY, or η).

Plot interaction

  • Mouse wheel inside the plot: zoom on both axes.
  • Mouse wheel over the x-axis: zoom 2θ only. Same for the y-axis.
  • Click and drag: pan.
  • Right-click anywhere on the plot: reset zoom.
  • The 2θ-min / 2θ-max sliders below the controls trim the fitting range; everything outside is shown but excluded from the refinement.

Output

Save Data writes a tab-separated text file containing the experimental intensity, the calculated total pattern, the refined background, and the difference, on the full 2θ grid. Generate PDF produces a multi-page report including refined parameters with their estimated standard deviations (from the LM covariance matrix), the full list of reflections sorted by 2θ, and the data table.
